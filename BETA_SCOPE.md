# Humanity's Nightmare - Beta Scope

## Current Input
The beta currently supports PC keyboard controls:

- W A S D or arrow keys: move
- Left Shift while moving: run

## Gamepad Support
Gamepad support is planned for a later iteration. It is not required for the first beta because the proposal specifies PC keyboard and mouse.

When the core beta loop is complete and stable, the team can replace the direct keyboard input code with Unity Input Actions and add gamepad bindings without changing the game design.
